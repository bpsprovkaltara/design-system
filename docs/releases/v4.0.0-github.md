# GitHub Release — v4.0.0 (salin ke isi rilis GitHub)

**Judul:** `v4.0.0 — React 19, Tailwind 4, Node 20+`

## Ringkasan

Rilis major internal: stack konsumen **React 19**, **Tailwind CSS 4**, dan **Node.js 20+**. Panduan migrasi dari v3: `UPGRADE_NOTES.md` (akar repositori).

## Breaking

- **Peer:** `react` / `react-dom` **≥ 19**, `tailwindcss` **≥ 4**
- **`engines.node`:** **≥ 20**
- Ekspor **`@bpsprovkaltara/design-system/tailwind-preset`** deprecated (shim + peringatan); rencana hapus v5 — gunakan impor **`styles.css`** + konfigurasi Tailwind 4 mandiri di aplikasi.

## Yang berubah (teknis)

- Vite 8, TypeScript 6, komponen tanpa `forwardRef` (pola ref React 19).
- **Docker:** image build/runtime **Node 20** + **pnpm** + `pnpm-lock.yaml` (bukan Bun + npm lock).
- **CI:** GitHub Actions menjalankan typecheck, lint, test, `build:lib`, dan `build`.

## Artefak npm

- `dist/index.js` / `.cjs`, types, `styles.css`, shim `tailwind-preset`.
