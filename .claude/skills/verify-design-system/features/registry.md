# Registry komponen

## Sub-features
Registry menyediakan JSON komponen yang dibangun dari source.

## How to get to it (user POV)
Buka `/r/button.json` pada showcase hasil build.

## Driving it with Playwright
Helper mengambil endpoint, memeriksa HTTP sukses dan isi salah satu file sama dengan `src/components/ui/button.tsx`, lalu menyimpan ringkasan JSON.

## Gotchas
Satu komponen dicocokkan; registry lengkap dan pemasangan konsumen belum dibuktikan.
