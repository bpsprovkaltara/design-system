# Tema

## Sub-features
Showcase menyediakan mode terang dan gelap.

## How to get to it (user POV)
Buka halaman Buttons dan gunakan tombol tema pada sidebar.

## Driving it with Playwright
Helper mengklik tombol berlabel `Aktifkan mode gelap`, menunggu class `dark` pada elemen HTML, dan menyimpan screenshot.

## Gotchas
Helper memulai dengan preferensi terang; persistensi setelah reload belum dibuktikan.
