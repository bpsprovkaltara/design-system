# Tombol

## Sub-features
Halaman menampilkan varian dan ukuran tombol.

## How to get to it (user POV)
Buka `/components/buttons` di showcase.

## Driving it with Playwright
Jalankan `scripts/verify-design-system.sh`: judul `Buttons` dan tombol `Default (Primary)` harus terlihat. Simpan screenshot dan ARIA sesuai skill.

## Gotchas
Contoh tombol lain tidak dibuktikan oleh helper.
