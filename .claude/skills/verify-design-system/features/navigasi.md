# Navigasi komponen

## Sub-features
Sidebar menghubungkan dokumentasi dan contoh komponen.

## How to get to it (user POV)
Buka showcase dan pilih komponen dari navigasi.

## Driving it with Playwright
Helper memilih link sidebar `Buttons` dari halaman awal dan memastikan URL `/components/buttons` serta heading `Buttons` terlihat. Screenshot dan ARIA tersimpan sebagai bukti.

## Gotchas
Rute dan menu lain belum dibuktikan oleh helper.
